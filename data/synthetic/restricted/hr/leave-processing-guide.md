# Fictional HR Leave Processing Guide

**Document ID:** HR-001  
**Classification:** Restricted  
**Required role:** HR Adviser  
**Synthetic:** Yes

This document describes an invented process for demonstration purposes only.

The HR Adviser checks that a fictional leave request contains the requested dates, leave category, and manager acknowledgement.

The adviser records the request in the fictional HR system and sends the employee a confirmation.

This process must never be used for real employment decisions.
