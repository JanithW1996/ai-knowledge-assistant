# Use Case

## Fictional organisation

Example Services Group is a completely fictional organisation created only for this project.

It provides administrative and technology support services. All names, documents, policies, teams, and events in this project are invented.

## Business problem

Employees spend too much time searching through internal guidance documents.

The AI Knowledge Assistant will help authorised users:

- find relevant fictional policies and procedures
- receive short answers based on approved documents
- see which documents support each answer
- access only information permitted for their role

## Users

- Employee
- Manager
- HR Adviser
- IT Support Officer

## Initial scope

The assistant may answer questions about:

- general workplace guidance
- leave procedures
- IT support procedures
- manager guidance

## Out of scope

The assistant must not:

- make employment or disciplinary decisions
- provide legal, medical, or financial advice
- access real organisational information
- reveal documents outside the user’s permitted access
- treat generated answers as guaranteed facts
